# Ultra Roofer Peak Authority

Premium, responsive website concept for Ultra Roofer Peak Authority in Los Angeles.

## Deploy on Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Leave the framework preset as **Other** and click **Deploy**.

No build command, environment variables, or package installation is required.

## Files

- `index.html` — complete website with embedded CSS and JavaScript
- `vercel.json` — static hosting and security-header configuration

Before using the site as the business's official website, replace illustrative imagery with approved project photos and confirm all service-area and service claims with the owner.
